# 스파크 서바이버 (Spark Survivor)

한 손으로 즐기는 **생존 로그라이크**(뱀파이어 서바이벌류). 작은 빛 "스파크"가 되어 몰려오는
어둠의 무리를 14분간 버틴다. HTML5 Canvas 단일 문서로 구현, **웹 전용**으로 배포된다.

## 플레이 방법
- **이동**: 화면 아무 곳이나 누른 채 드래그(플로팅 조이스틱). 데스크톱은 WASD/방향키.
- **공격**: 보유 무기가 자동 발사. 위치 선정이 곧 조준이다.
- **성장**: 적을 처치하면 경험치 젬이 떨어지고, 모으면 레벨업 → **3장의 카드 중 1개**(새 무기/강화/패시브) 선택.
- **진화**: 무기 Lv5 + 짝 패시브 Lv3 이상이면 엘리트의 골든 체스트로 무기가 진화한다.
- **보스**: 2분마다 엘리트, 13:56에 최종 보스. 14분 생존/보스 처치 시 승리, 이후 무한 모드.
- **메타**: 런에서 모은 **골드**로 시작 화면 강화 상점에서 영구 업그레이드.

무기 7종(오빗/오라/랜스/스캐터/체인/시커/부메랑) · 적 6종+보스 · 미니멀 플랫 아트.

## 구조 / 빌드
- 게임 원본은 **`game/gameHtml.js` 한 곳**(템플릿 리터럴 안의 단일 HTML 문서).
- `node scripts/gen-web-game.js` 실행 → 저장소 루트 **`game.html`** 생성(localStorage 저장 +
  iOS '홈 화면에 추가' 메타 주입). 게임 수정 후 이 스크립트를 다시 돌리면 된다.
- **웹 배포**: GitHub Pages가 저장소 루트를 서빙 → `https://timlikeanjimin.github.io/hijimin/game.html`
  (`main` 브랜치 push 시 자동 배포).
- 진행상황(골드·메타·최고 기록·설정)은 기기에 저장된다.

> 이 폴더의 Expo 앱(App.jsx/app.json 등)과 APK 빌드 워크플로는 **웹 전용 전환으로 더 이상 사용하지 않는다**
> (APK 워크플로는 수동 실행만 가능하도록 비활성화됨).
