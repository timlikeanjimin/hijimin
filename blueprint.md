# Lotto Number Generator

## Overview

This is a simple web application that generates 6 unique lottery numbers between 1 and 45.

## Features

*   Generates 6 unique random numbers.
*   Displays the numbers in a user-friendly interface with animations.
*   Allows the user to generate new numbers with a button click.

## Design

*   **Visuals**: The application has a bold, modern, and engaging design.
*   **Layout**: The layout is responsive, ensuring a great experience on both mobile and desktop devices.
*   **Color Palette**: A vibrant and energetic color palette is used, with gradients and drop shadows to create depth.
*   **Typography**: Uses the "Poppins" font from Google Fonts for a clean and modern feel.
*   **Texture**: A subtle noise texture is applied to the background for a premium, tactile feel.
*   **Animation**: Numbers are animated on generation, and interactive elements have hover effects.
*   **Iconography**: While simple, the design uses clear visual cues.
